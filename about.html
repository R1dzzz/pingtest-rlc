Tentang proyek

Tujuan

Memberi cara sederhana dan jujur untuk memeriksa kualitas internet dari HP maupun laptop, sekaligus menjadi proyek belajar jaringan: memahami perbedaan kecepatan (bandwidth), latency, jitter, dan bufferbloat.

Teknologi

Frontend-only dengan Vite, HTML, CSS, dan JavaScript. Pengukuran memakai @cloudflare/speedtest (MIT). Tanpa backend, tanpa API key, riwayat tersimpan di LocalStorage. Dihosting sebagai static site di Vercel.
