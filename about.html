Tentang Produk

PingTest by RLC adalah alat uji kecepatan dan kualitas jaringan internet berbasis web. Pengukuran download, upload, latency, dan jitter dilakukan dengan @cloudflare/speedtest resmi — bukan simulasi. Situs tidak memerlukan API key, tidak menyimpan data pribadi, dan seluruh riwayat tes disimpan secara lokal di perangkat Anda (LocalStorage).

Proyek ini dibuat untuk komunitas TJKT, khususnya siswa SMK Tamtama Karanganyar, dan siapa pun yang ingin memeriksa kualitas koneksi internet dengan cepat di perangkat mobile.
